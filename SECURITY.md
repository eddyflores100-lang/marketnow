# Security Policy

## Reporting

Report suspected vulnerabilities privately through GitHub Security Advisories if enabled, or through AliceLabs' published business contact channel. Do not publish exploit instructions, credentials, private keys, customer data or unredacted logs in public issues.

Include affected component and version, reproduction steps, impact and a safe proof of concept. Distinguish vulnerabilities in the public catalog/site from issues in the separate product-code and protocol repositories.

## Scope

This repository owns the MarketNow live marketplace, catalog data, scheduled data pipelines and related site deployment. Product code and protocol responsibilities are maintained in the separate repositories identified in README.

Never commit signing keys, provider tokens, deployment secrets or private customer data. Treat security scores and static analysis results as evidence with stated scope, not a guarantee that a tool or agent is safe.
