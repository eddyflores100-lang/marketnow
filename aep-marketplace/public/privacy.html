MarketNow — Privacy Policy

Effective: 2026-09-30 marketnow.site

Scope

This policy covers https://marketnow.site, including the free, no-authentication MCP endpoint at /api/mcp and the marketplace pages.

What the MCP endpoint processes

The endpoint is a stateless query service. Tool calls (tools/list, credential verification, format translation, domain risk checks, revocation lookups, registry search, tool fingerprinting) process the arguments of each call to produce a result:

  • Credential samples sent to marketnow_verify_trust or marketnow_translate_credential are parsed in memory to compute a verdict. Credentials are not published anywhere by these tools.
  • Domain names sent to marketnow_check_domain are evaluated against MarketNow's scam-check engine.

Skill submissions

Content published through marketnow_submit_skill is stored in the public auditable review queue with the package metadata you submitted (repo URL, install command, descriptions). This is published catalog data about the software package, not personal user data. A dry_run option runs full validation and stores nothing.

Accounts, cookies and tracking

The MCP endpoint requires no account and no authentication. We set no tracking or advertising cookies on the endpoint. We do not sell or share query data.

Infrastructure logs

Standard server logs (request timestamps, IP addresses, user agents) are generated by our hosting providers (Vercel, Cloudflare) for security and abuse prevention, and retained per their policies.
